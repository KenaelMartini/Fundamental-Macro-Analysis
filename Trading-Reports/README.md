# 📊 Trading Reports — Daily / Weekly / Monthly / Quarterly / Yearly

This repository documents my **institutional trading process** across multiple time horizons.  
Every day, week, month, quarter, and year I publish structured reports to prove discipline, consistency, and progress — just like an institutional desk would.

---

## 📅 Report Levels

- **Daily** → Execution checklist (AM/PM) + mini recap (3–5 lines).  
- **Weekly** → Tactical synthesis of the week, execution KPIs, and next week’s watchlist.  
- **Monthly** → Dominant macro themes, currency biases (traffic lights), recurring mistakes and fixes.  
- **Quarterly** → Strategic macro theses, scenarios A/B/C, process KPIs, roadmap Q+1.  
- **Yearly** → Big-picture macro view, personal progression, achievements, and roadmap Y+1.

## 🧩 Workflow

1. **Every Morning**
   - Fill the **Daily checklist (AM)** using `TEMPLATE_DAILY.md`.

2. **Every Evening**
   - Complete the **PM section** + write a short mini recap (3–5 lines).
   - Commit file under `/daily/YYYY/Www/`.

3. **Every Sunday**
   - Publish **Weekly Report** in `/weekly/YYYY/` (using `TEMPLATE_WEEKLY.md`).

4. **End of Month**
   - Publish **Monthly Report** in `/monthly/YYYY/` (using `TEMPLATE_MONTHLY.md`).

5. **End of Quarter**
   - Publish **Quarterly Report** in `/quarterly/YYYY/` (using `TEMPLATE_QUARTERLY.md`).

6. **End of Year**
   - Publish **Yearly Report** in `/yearly/YYYY.md` (using `TEMPLATE_YEARLY.md`).
