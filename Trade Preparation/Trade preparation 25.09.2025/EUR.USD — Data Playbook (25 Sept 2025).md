# 📊 EUR.USD — Data Playbook (25 Sept 2025)

## 1. Context
- Yesterday: EUR/USD sold off on IFO miss + Trump/OTAN headlines.  
- Overnight: Asian session consolidation, **no stop hunt yet**.  
- Today: US data at 14:30 → Final GDP + Unemployment Claims + Durable Goods.  

---

## 2. Drivers to Watch
- **Final GDP q/q (exp. 3.3%)**  
  - Above → USD+, bearish EUR/USD.  
  - Below → USD-, bullish EUR/USD.  
  - At consensus → neutral, no direct impact.  

- **Unemployment Claims (exp. 233k, prev. 231k)**  
  - Above → USD-, bullish EUR/USD.  
  - Below → USD+, bearish EUR/USD.  
  - At consensus → neutral.  

- **Durable Goods Orders** (exp. -2.8% headline, +1.0% core)  
  - Positive surprise → USD+, bearish EUR/USD.  
  - Negative surprise → USD-, bullish EUR/USD.  

---

## 3. Stop Hunt Hypothesis
- **Scenario A: Stop hunt before data**  
  - Liquidity grabbed → books cleaned.  
  - If data neutral → EUR/USD retraces higher (technical correction).  
  - If data weak → EUR/USD rallies harder (double bullish).  
  - If data strong → continuation lower, stop hunt = pre-break.  

- **Scenario B: Stop hunt at data release**  
  - If numbers confirm direction → no retrace, trend extends.  
  - If numbers neutral → high volatility chop, risk of false signals.  

- **Scenario C: No stop hunt before data**  
  - Market holds levels into release.  
  - Reaction purely driven by surprise in data.  
  - Higher risk of violent spike + thin liquidity at 14:30.  

---

## 4. Trilateral Desk Scenarios
1. **Strong US Data (GDP > exp. + Claims < exp. + Durables strong)**  
   → USD double/triple support → **EUR/USD down**.  

2. **Weak US Data (GDP < exp. + Claims > exp. + Durables weak)**  
   → USD double/triple weakness → **EUR/USD up**.  

3. **Mixed / Consensus Data**  
   - If stop hunt already happened → EUR/USD retraces higher (technical squeeze).  
   - If no stop hunt yet → wait, possible post-data flush before direction.  

---
